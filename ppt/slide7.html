风险识别与应对

AI API 不可用

网络问题、额度耗尽、服务宕机导致核心功能中断。

应对：内置离线规则引擎降级；支持多 Provider 切换（OpenAI / DeepSeek / Ollama 本地）。

环境兼容性

Windows 缺少 /proc 文件系统，Shell 脚本无法原生运行。

应对：开发用 WSL2 / 虚拟机；脚本添加环境检测提示；演示优先使用 WSL。

日志权限不足

/var/log 路径下部分文件需 root 权限读取。

应对：脚本检查可读性；给出 sudo 提示；提供模拟日志文件用于无权限环境演示。

工作量压力

2 人 3 周完成全部功能可能时间紧张。

应对：核心路径优先（采集+诊断+报告）；SSH 远程等扩展功能作为加分项后延；每日沟通同步。
